Create and manage block templates for different post types within your WordPress website. Perfect for sites with tons of post types!

== Installation ==

1. Go to 'Plugins > Add New' on your WordPress admin dashboard.
2. Search for 'Manage Block Template' plugin from the official WordPress plugin repository.
3. Click 'Install Now' and then 'Activate'.
4. To get started, head over to the 'Manage Block Template' menu option and click on 'Templates'.
5. Create a template by simplying placing the blocks of your choice into the editor and save.
6. Now, head over to the Settings menu option.
7. You should see different posts mapped to different templates.
8. For Posts, select the template you just created and save.
9. Go to Posts, you should now see the block template in place.

== Description ==

Creating and managing block templates for different post types within your WP website doesn't have to be rocket science! With this plugin, you can easily create multiple block templates of your choice and assign them to specific post types within your website. It's fast and super easy to use. This plugin is perfect for website owners who run blogs, news or websites with tons of post types!

Now, you have one less to worry about...

= ✔️ Features =

The plugin provides the following capabilities:

✔️ <strong>Templates</strong>: Dashboard for creating block templates. Simply drag and drop.
✔️ <strong>Settings</strong>: An options page for mapping templates to post types.
✔️ <strong>Custom filters</strong>: `manage_block_template_post_types`, `manage_block_template_blocks`, `manage_block_template_admin_fields` for customizing plugin options.
✔️ Available in <strong>multiple langauges</strong> such as Arabic, Chinese, Danish, Hebrew, Hindi, Russian, German, Italian, Croatian, Spanish & French languages.
✔️ Super fast and easy to work with.
✔️ <strong>Backward compatible</strong>, works with most WP versions.

= ✨ Getting Started =

1. Head over to the 'Manage Block Template' menu option and click on 'Templates'.

3. Now, proceed to the Settings menu option. You should see different posts mapped to different templates.

4. For Posts, select the template you just created and save.

You can get a taste of how this plugin works, by using the [demo](https://tastewp.com/create/NMS/8.0/6.7.0/manage-block-template/twentytwentythree?ni=true&origin=wp) link.

= 🔌🎨 Plug and Play or Customize =

The Manage Block Template plugin is built to work right out of the box. Simply install, activate and start using.
