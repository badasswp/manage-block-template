# Changelog

## 1.0.0
* Initial plugin release.
* Added dashboard for creating block templates.
* Added menu options page for mapping templates to post types.
* Added custom filters `manage_block_template_post_types`, `manage_block_template_blocks`, `manage_block_template_admin_fields` for customizing plugin options.
* Available in 11 international translations - French, Spanish, Hebrew, Hindi, Arabic, Danish, Croatian, Russian, Italian, German & Chinese.
* Update README docs.
* Tested up to WP 6.8.
